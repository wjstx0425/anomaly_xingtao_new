### 1.2 每个项目的可观测边界

| 原序号 | 原名称 | 本轮二维图像试验对象 | 不能用图像试验偷换的要求 |
|---|---|---|---|
| 1 | 开裂 | 已张开、存在可见裂口或缝隙的区域 | 不凭暗线直接认定断裂工艺原因 |
| 2 | 隐裂（微裂） | 经质量人员确认、且确有可见表面征兆的子集 | 闭合或内部裂纹可能无稳定表面信号；不得宣称普通二维图像覆盖全部隐裂 |
| 3 | 划痕 | 划痕位置、投影形态与可见程度 | 原要求为“影响结构强度的深度划痕”；二维检测结果不是深度或强度量测 |
| 4 | 毛刺 | 指定关键边缘可见的突出或毛刺 | 板厚方向毛刺、遮挡毛刺和功能判废尺度要另行验证 |
| 5 | 变形 | 外轮廓、小脚等在当前视角可观察的形状偏差 | 外轮廓通过不代表扭曲、下塌等所有空间变形通过 |
| 6 | 压伤 | 较明显凹陷引起的可见形貌/明暗变化 | 明暗差或网络分数不能直接换算凹陷深度 |
| 7 | 油污 | 较大面积油污，以及指定关键区域油污 | 需区分允许油膜和判废油污；裂纹与油污可同时存在 |
| 8 | 表面氧化 | 发白、发黑、发黄等明显变色 | 三通道文件不保证有真实彩色信息，单色相机不能恢复缺失色度 |
| 9 | 成型挤料 | 堆叠、起皱、拱起等可见征兆 | 没有空间量测时，不声称已测增厚或鼓包高度 |
| 10 | 多料/少料 | 外轮廓缺口、余料、可见材料异常 | 外轮廓仅是子范围，不等于测出所有内部材料量或厚度变化 |

覆盖状态至少区分：`READY`、`NO_SAMPLES`、`NO_ANNOTATION`、`NOT_OBSERVABLE_IN_CURRENT_VIEW`、`MISSING_MODALITY`、`BLOCKED_ASSET`。没有样本的类别不可显示为100%通过率；不可见样件不能从需求覆盖清单中消失。

### 1.3 不把照明问题伪装成模型问题

同一方向的短/长曝光用于曝光量变化，不等于多方向光度立体输入。若未来测试光度立体，要另采同视角、多照明方向的数据，确认标定及反射条件；不能用目前的HDR两张图编造法向或毫米深度。[R12]

## 4. 数据审计：决定哪些实验今天能做

先输出`data_audit.md`与`requirement_coverage.csv`，不要先下载十个模型。

每个原始文件至少登记：路径、尺寸、实际通道/位深、型号、左右配置、语义视图、曝光/照明条件、物理零件ID、采集轮次、独立缺陷实例、是否有框/mask、标注完整性、质量结论来源。

`templates/image_manifest.csv`为空表头，需由本地真实数据生成。核心字段：

```text
image_id,physical_part_id,lineage_id,capture_id,session_id,part_number,hand,
view_id,condition_id,source_kind,image_path,width,height,color_mode,
annotation_path,annotation_status,split,provenance
```

- `physical_part_id`指实体零件，不是图片编号或采集group。
- `lineage_id`将同件正常/损伤前后、重拍、裁剪、增强、短/长/融合及跨视角关联起来；同一源谱系不得跨集合。
- 只有group编号而不知道是否重复使用实体零件时，先标身份不确定。不能把100次摆放宣称为100件独立样本。
- `hand`与`view_id`独立；文件名`left_front`不能自动等同于`front_left`。
- `source_kind=fused_only`时，即使接口有三个数组，也不计为三路独立曝光；查看实际源标志。
- 2047×1545示例图不能直接套4024×3036现场ROI；保留坐标变换，禁止静默resize后当同尺度量测。
- 三通道PNG可能只是灰度复制；真实色彩由相机/处理来源和通道检查共同确认。
- 不将所有名为`surface`的图分配给压伤、油污或氧化；含糊类别交人工映射，支持一个图含多个缺陷。
- 缺陷件的某一视角可能看不到缺陷，不能把整件NG机械地复制成八张图都NG。
- 无标注不等于正常。未完整标注的区域不能自动充当检测/分割的负样本。
- 原始图和标注只读；实验生成物写入独立目录。

标注文件建议按图保存JSON，字段包含`defect_instance_id`、`requirement_id`、`visible`、`bbox_xyxy`或`mask_path`、`annotation_quality`、`verification_source`。一个实体缺陷出现在多个视图时复用实例ID。单靠二维外观不能确认隐裂时，标注须记录外部质量确认来源或`unconfirmed`。

输出每项：独立正常件数、异常件数、可见视图数、完整框数、真mask数、重复拍摄数、未确认/不可见数。没有某类样本时记录缺口，不编造该类效果。

### 4.1 有哪些标注，就先开展哪些实验

| 当前资料 | 可以先做 | 不能声称已完成 |
|---|---|---|
| 可信正常图＋少量带类别的缺陷图 | 规则、已有EfficientAD/YOLO回放与输入诊断；图像/工件级评估 | 没有定位真值时，不能证明候选落在正确缺陷上 |
| 完整框标注 | 上述＋YOLO检测对照＋框级定位 | 不能将框填充为真实缺陷mask评估分割 |
| 人工审核的像素mask | 上述＋S01/S02/S03及mask定位评估 | 有mask不代表有实际深度/强度标注 |
| 多方向照明/标定深度 | 可新增对应形貌实验 | 必须新建成像条件分组，不与原RGB结果混为纯算法提升 |

标注成本要计入算法成本。有稀疏标注时，可显式建立稀疏损失/弱监督分支，但不能冒充普通全监督结果。

## 5. 分组划分与防泄漏

### 5.1 三层数据角色

- `train`：后续监督网络训练、参考模板、主体/统计规则拟合。EfficientAD默认只读已有权重；另需干净基线重训时必须先说明并获得确认。
- `dev`：超参数、图像方案、后处理、门限和融合选择。可在数据足够时进一步分`tune`和`calibration`；不足时记录共用，不伪称独立。
- `locked_test`：最终冻结后评估，不用于选择候选、阈值、mask、模板或最佳迭代。

按`lineage_id/physical_part_id`分组，再尽量保留不同日期/批次的外部测试。GroupKFold等分组工具可用，但必须先建立正确实体关联。[R14]

划分必须先于分块、增强、ROI裁剪和正常参考建立。同件八视图、两档曝光、融合图、重复取放和镜像派生数据不得分到不同集合。已多次展示、定位并调过参数的缺口示例归入开发/回归资料，不能再称为未见测试。

当每类独立NG很少：使用分组交叉验证或只做开发性质的逐样件对照；给出每类`k/n`，缺失类别N/A。没有资格用大量增强图填充独立样本数。若使用交叉验证，每折新候选参考、监督模型和阈值均仅用该折训练/开发数据建立。冻结旧EfficientAD的来源与交叉验证训练范围不同时，单列部署回放，不伪称同折重训。

### 5.2 旧权重的污染检查

当前模型若见过拟测试零件，或无法核实训练来源：

1. 可以保留为“当前部署行为回放”，但不能放入干净泛化排行榜。
2. 优先使用真正新增且实体不重叠的测试件；本轮不自动重训EfficientAD。若确需重训才能完成干净对照，报告原因并单独请求确认；在此之前仅做部署回放/开发诊断。
3. 在每行指标记录`evaluation_track=deployment_replay|clean_split|development_only`，不可混合排名。

`fit`、阈值校准、特征缓存、模板选择、归一化统计均应有输入集合清单；尤其检查anomalib默认验证/后处理是否自行划分数据或更新阈值。不得在locked_test上调用会重新拟合阈值/归一化的默认验证流程。

## 6. 单算法试验的具体实现要求

### 6.1 R01整圈轮廓

复用《兴韬_BMW整圈外轮廓检测_Codex实现说明_V1.0.md》：一次辅助标准建立；独立基准刚性对齐；实际待测整圈提取；双向点到线段距离；连续异常边段；未覆盖边段显式输出。

不以模板轮廓替代真实待测边缘，不使用凸包修补缺口，不允许缩放/局部形变把缺陷对齐掉。分类初始为`contour_anomaly`，向内/向外/混合记录，不强行把所有形状异常分成变形、多料或少料。

有`gap`而没有足够实际边缘证据时输出REVIEW；有确定异常同时别处未观察完整时保留NG与覆盖缺口两个事实，不能将未知变成PASS。

### 6.2 R02a/b细线

固定区域/分块 → 独立低频背景处理 → 黑帽/顶帽或脊线响应 → 阈值/连接 → 连通域描述 → 候选区域与连续程度。

R02a先试少量尺度及方向；参数由原图中的目标宽度范围和dev确定。保留暗线与亮线两路，不只看暗裂纹。R02b优先复用`skimage.filters.sato`或`frangi`，不把未经核对的自制实现称为Steger。

输出响应图、候选mask/框、面积、骨架长度、局部宽度和方向。规则只能说明存在细线证据；正常油膜边界、压筋、划纹、高光都是必须纳入的负例。短而宽的开裂不应被“长宽比必须很大”的唯一规则全部排除。

R02作为独立候选分支先运行；尚未证明高召回前，不把它作为深度分割唯一的前置裁剪器。

### 6.3 R03参考残差

对同型号、视图、成像条件的正常train做受约束对齐；计算每像素中位数`m`和MAD尺度`a`。示例残差：

`r(x)=abs(I(x)-m(x))/(1.4826*a(x)+epsilon)`。

`epsilon`和统计估计版本可配；MAD为0时必须处理。这是可解释统计基线，不是毫米深度。不要对每张测试图进行任意局部亮度拟合，将大面积油污或氧化也归一化掉。亮度补偿仅限事先验证的稳定控制区域。

输出像素残差与连通域，严控配准边界假差。不要只计算整图SSIM平均值；若增加局部SSIM，作为独立变体记录，不能只保存漂亮差分图而没有判定规则。

### 6.4 R04颜色/区域规则

固定成像和指定区域 → RGB/BGR约定检查 → Lab或其他明确颜色特征 → 对正常train颜色范围求偏离 → 按面积、位置与边界样件判定。

明确RGB范围、Lab转换约定、色差实现；不能把OpenCV 8-bit编码值与标准浮点Lab混用。[R6]

真实彩色不足时，允许做发黑/发白的灰度变化实验，但记录`capability=grayscale_appearance_only`；不能宣称识别发黄色差。区域外允许的油膜可为油污任务负例，但不能让裂纹任务直接忽略该区域。关键区域被油污遮住时，额外记录裂纹观察不完整。

### 6.5 R05纹理/皱褶

在限定成型区求方向滤波响应、局部能量/方差、方向一致性，与正常统计比较。先以Gabor或梯度统计二选一起步，避免滤波器笛卡尔积。输出区域和纹理统计，禁止将规则分数命名为“挤料厚度”。

### 6.6 B-E：冻结并复用EfficientAD

记录当前权重、预处理、公共ROI、ignore mask、异常图归一化、连通域过滤、阈值和分数聚合方式，保存只读基线快照。先验证相同输入得到可复现结果；保持与真实部署一致，不为对照修改其能力。

默认不改变权重、阈值、输入分辨率，也不重新训练。若本地有新版本，使用用户当前实际运行版本并记录，不回退旧远端快照。

不为本轮下载或初始化其他异常检测网络。若基线缺资产，只报告`BLOCKED_BASELINE_ASSET`，新规则可做独立开发验证，但此时不能计算真实“相对基线新增检出”。

输出原始异常图、空间回映射、原始分数和最终判定；不得逐测试图min-max后当统一报警分数。该输出是无类别异常证据；类别分层评价由evaluation端关联真值完成。

**有效可见部位上EfficientAD输出PASS，不能阻止其他新分支运行。**融合时保留各分支结果，具体加法收益通过dev验证，而不是先建立一个可能吞掉假阴性的前置门控。

### 6.7 D01/D02检测对照

先确认实际基线`imgsz`。若是640，可将下列组合作为起始设计，而不是保证最佳参数：

| 变体 | 结构 | 输入策略 | 说明 |
|---|---|---|---|
| Y-base | 当前YOLO26n | 当前策略 | 冻结回放；训练来源未知另标 |
| Y-n-low | YOLO26n | 640整体ROI | 同一干净train重训的比较基线 |
| Y-n-high | YOLO26n | 1280整体ROI | 对比输入分辨率；单独记录训练/推理条件 |
| Y-n-tile | YOLO26n | 原图确定性640级分块，重叠可从20%试起 | 保存所有块、回映射和去重成本 |
| Y-s-high | YOLO26s | 与已选n方案完全相同 | 容量对照，不同时改变一堆条件 |

n/s与检测/分割为官方支持的选项，但具体本地版本参数要实查，不能按最新网页强制升级现场依赖。[R13]

E2先做`inference_only`：保持现有YOLO26n权重不变，比较当前输入与一个更高分辨率输入；预算允许再试一个确定性分块输入。推理参数和实际letterbox尺寸参考本地API，[R16]只作官方依据。仅提高旧权重推理分辨率不能替代对应训练条件的验证，诊断无收益也不直接证明分块无效。E3条件具备后，再在干净train上匹配输入策略训练并比较。不同结构可使用相同有限调参预算，不应被迫沿用明显不适合的同一学习率。

测试/部署分块必须不依赖真值位置；不能用GT中心裁剪证明可部署检出率。训练可从已标注缺陷采正块，但须包含完整标注的正常/硬负块。跨块缺陷保留截断标志和一致归并规则；mask/框回原图，合并后才计算实例数和误报。

禁止默认采用会破坏物理语义的强透视、翻面、任意颜色扰动。增强只在train上，且单独消融。小缺陷尤其记录原图宽度、缩放后宽度和实际网络输出尺度。

### 6.8 S01/S02/S03分割

有真实mask后，优先选一到两类最急需、样本条件最好且边界可标的缺陷，例如开裂/划痕；先试二值缺陷分割，不强求第一版十分类。

S01可用小型U-Net加预训练编码器，S02用SegFormer-B0；API/依赖由本地环境决定。网络家族依据[R10、R11]，面向冲压件的具体数据和损失为新实验设计。

初试损失用BCE+Dice，并对未标注像素设ignore；多类使用与标签类型相符的损失。分块、正负采样与模型容量分别记录。mask不足就标BLOCKED_MASK，继续有框的D01和规则试验，不恢复无监督模型搜索。不能自动用矩形框、正常轮廓补全或生成模型输出充当真实像素真值。

辅助标注可以自动生成候选，但人工审核后才能记为真值；评估标注尤其不能完全由被测模型自己生成。不得在评估集上回传训练信号。

## 8. 统一输入、输出和模块结构

建议接口（名称待实现；按本地已有接口调整）：

```python
class AlgorithmAdapter(Protocol):
    def fit(self, train_data, config, artifact_dir): ...
    def predict(self, inputs_without_ground_truth, fitted_artifacts): ...

# 独立于predict执行：
# calibrate(dev_predictions, dev_labels, policy) -> frozen_thresholds
# evaluate(test_predictions, test_labels, frozen_thresholds) -> report
```

`predict`只能接收图像、已批准的空间ROI/视图/成像元数据，不接收真值、缺陷类别、损伤位置或normal/defect目录逻辑。Evaluation端再关联真值。

统一预测至少包含：

```text
run_id,algorithm_id,image_id,capture_id,view_id,condition_id,
execution_status,decision,raw_score,score_direction,threshold,
boxes/masks/contour_events,coordinate_transform,
observed_regions,missing_regions,evidence_paths,
preprocess_ms,inference_ms,postprocess_ms,reason
```

`decision=PASS|NG|REVIEW|ERROR`；不适用状态单独记录。配置错误和模型缺失不可伪装成PASS。每个适用输入必须有一条成功或失败记录，不允许缺失行在汇总中被静默删除。

几何分数为像素/距离，异常分数和置信度有不同含义；各自记录score方向及门限。无连续分数的规则仍可输出判定与观测量，不伪造概率。轮廓结果可回映射到原图坐标，内部热图保持实际分辨率，插值上采样不能冒充原生像素分辨能力。

建议目录：


## 9. 评价：先问有没有补到真正的缺陷

### 9.1 三种粒度都要有，不能混用

1. **工件/检测周期**：完整八视图或批准的必检视图汇总后是否正确拦截；正常件是否被误判/要求复检。
2. **缺陷实例**：一件上每个真实缺陷是否被定位到。一个裂纹在三张图可见仍是同一实例，不能按三次独立缺陷算。
3. **单视图/局部区域**：用于分析哪台相机和哪个ROI有问题，不作为独立实体样本数。

若一个裂纹件因为螺钉反光而被判NG，可以算“该工件被拦截”，不能算“裂纹成功定位”。没有框/mask时，只报告工件/图像级拦截；定位能力N/A。

常规框任务可使用预先约定IoU阈值的一对一匹配；像素mask任务可计算Dice/IoU。细线mask的容差定位可另设，但容差在dev确定，且加预测面积/宽度或精度约束，不能让整件涂红获得高检出率。不同定位协议分表，不将框AP与mask Dice排成同一总榜。

异常检测未输出类别时，可按真实缺陷类分层统计是否命中，但不能称为十类分类准确率。多缺陷实例通过位置匹配分配，防止任意一个NG为所有类别加分。

### 9.2 必须输出的指标

| 指标 | 定义/说明 |
|---|---|
| 每项实例检出率 | 正确定位的真实缺陷实例数/对应已标注实例数；显示k/n |
| 缺陷工件自动检出率 | 系统输出NG的缺陷工件数/全部目标缺陷工件数 |
| 缺陷流出率 | 缺陷工件输出PASS的比例；REVIEW/ERROR单列，不能当自动检出 |
| 正常件NG误报率 | 正常件输出NG/正常件总数 |
| 正常件复检率/错误率 | REVIEW、ERROR分别报告 |
| 正常件非自动放行率 | (NG+REVIEW+ERROR)/正常件总数，避免以全部送复检换漂亮漏检率 |
| 定位质量 | 依据真实标注类型，报告框/像素或轮廓偏差指标 |
| 有效覆盖 | 规定区域/视图是否观察充分；部分ROI结果不能代表完整需求 |
| 运行成本 | p50/p95延迟、显存/内存峰值、训练时间、标注时间 |

同时报“可见有效子集的算法效果”和“全部需求样件的端到端结果”。对不可见的隐裂、缺失视角或无深度的要求，覆盖清单明确未解决，不能剔除后给出整个项目100%召回。

重复摆放的所有检测周期可用于操作稳定性统计；泛化置信区间以独立实体/谱系为单位，或按实体聚类重采样。不可用裁剪块和增强图扩大置信度。

### 9.3 在同一正常件误报约束下比较

建议在dev按正常件非自动放行率设置1%、3%、5%等**研究工作点**，具体选哪个由数据规模和业务目标确定，并非甲方批准指标。

每个新候选/组合在dev选阈值后冻结；EfficientAD仍使用其冻结基线参数。locked_test报告实际出现的误报/复检比例，不能为了让测试误报恰好等于目标再调阈值。多视图取最大、ROI数量、分块合并、质量门控等必须包含在校准链内，不能只校准单图阈值后宣称整件误报相同。

样本不足时给出经验k/n，不假装验证了极低误报。作为统计解释：若n件真正独立正常件0次误报，二项模型的一侧95%上界为`1-0.05**(1/n)`；n=100约2.95%。重复图片不满足独立条件时不能套用此公式。这个例子仅解释证据强度，不是本项目已有测试结果。

AUROC、AP可作辅助，但不替代固定工作点下的逐类检出、流出、复检、覆盖和延迟。不要让大量背景像素或大量正常件掩盖小缺陷漏检。

## 10. 互补性与融合：新模型是否值得留下

设B为冻结基线、A为新候选。在相同评估单位和预定匹配条件下，先计算：

- `new_hits = TP(A) - TP(B)`：基线漏掉而A正确检出的实例/工件。
- `added_false_alarms = FP(A) - FP(B)`：正常件中新增加的误报。
- `shared_misses`：两者均漏掉的目标。
- `unique_failures`：A新失败但B通过/检出的情况；结合延迟和覆盖分析。

这里的集合差是固定阈值的诊断，不等于最终部署收益。简单OR会增加拦截也可能增加正常件误报；正式组合需在dev上校准新增分支，并报告同等非自动放行负担下的结果。EfficientAD的冻结参数保持不变；若某目标低于冻结基线自身非放行率，报告该工作点不可达，不偷偷放宽旧阈值。必须改基线时另立版本、说明原因并获确认。

优先测试少量可解释组合：`B+R01`、`B+R02a`、`B[D01替换旧YOLO]`、`B+S01`、`B+R01+一个最佳表面分支`。其中B是冻结现场基线；YOLO输入/容量对照默认替换原YOLO分支，不将多个YOLO全部叠加后宣称单模型改进。根据dev新命中模式决定最多约10个预登记组合，不做所有候选子集穷举后用测试集选最高值。

禁止直接平均模板距离、异常分数和YOLO置信度。可用各自锁定门限的决策，或dev建立的分数映射；任何标定都不允许使用测试真值。

多视图不要求同一缺陷每张图均检出；融合基于可见性和必检区域。某算法不适用于某项不等于这项自动通过。只留下能够在同等约束下补检、减少错误或显著降低成本的分支；重复报同一缺陷但没有独立收益的模型可淘汰。

最终推荐表要写：保留、仅复核使用、需改善成像、标注不足、淘汰及对应证据。不以“新增算法数量”作为成果指标。

## 11. 运行成本与可复现记录

训练/拟合计时包括监督训练与规则参考统计构建等；推理报告解码/预处理/前向/后处理/跨块与跨视图合并，证据写盘另列。常驻模型加载时间和冷启动单列，不与稳态推理混在一起。

GPU操作异步；测量需预热并同步，或使用经验证的benchmark工具。PyTorch官方benchmark教程明确讨论预热与CUDA同步问题。[R15]

主对照固定硬件、precision、batch、线程数和输入方案。训练可以并行，正式延迟测试不要与其他重负载GPU作业同时运行。报告按一个完整工件所需的所有视图/ROI/tiles，而不是只报一张小裁剪图的耗时。

记录`git_sha`、dirty diff摘要、env/锁文件、GPU型号、数据划分摘要、配置快照、随机种子、权重来源、训练图清单、调参次数、阈值来源和完整命令。对于已有权重，只记录可核实信息，不编造训练epoch或耗时。

资源计划可沿用用户此前提到的多GPU资源，但必须检测当前可用设备。先单种子筛选，入围的学习候选再做多种子或多组划分稳定性；结果不足时标“初筛”，不承诺通用排名。

## 13. 必须有的测试

| 测试 | 应保证的行为 |
|---|---|
| 同件跨视图/曝光/增强泄漏 | 划分校验失败；缺实体映射明确警告/阻止干净排名 |
| 把train模板/训练样件加入test | 必须检测或由来源清单阻止 |
| 替换文件名中的normal/defect | 预测不变，不读取标签性路径逻辑 |
| 未标注区域/未知类别 | 不按正常负样本使用，不强行映射原第1—10项 |
| 仅融合图复制到短/长槽位 | 不作为真实三通道曝光证据 |
| 变更图像尺寸/ROI坐标 | 明确变换或ERROR，不静默修复为可验收尺寸 |
| 分块跨边界缺陷 | 回原图归并后只算同一真实缺陷，边界漏检留痕 |
| 候选异常在真缺陷之外 | 工件拦截与缺陷定位统计不同 |
| 正常件全部REVIEW | 正常非放行率很高，不能呈现为优秀模型 |
| locked_test改标签后再跑预测 | 预测/门限不变，仅评价变；不能自动调参 |
| 新算法输出缺失、NaN、OOM | 失败记录保留，分母不静默缩小 |
| 规则误差/距离原始单位 | 不伪装成概率/毫米；正负方向和坐标可回查 |
| baseline兼容性 | 实验不改变现场profile、钢印、当前结果合同与现有测试；优先尊重本地新增功能 |
| EfficientAD基线漂移 | 权重、输入、ignore mask、后处理或阈值发生变化时拒绝继续冒用冻结基线ID |
| 新无监督深度模型入队 | 非EfficientAD的此类模型被策略校验拒绝；不得因S01缺mask自动改跑其他AD |
| EfficientAD正常而新分支异常 | 新分支照常执行、保留证据，避免旧模型前置门控阻断补检 |
| YOLO替换/叠加混淆 | 默认按分支替换比较；双YOLO叠加另登记，不混称单模型提升 |

这些通过说明软件协议正常，不代表工业检出率通过。真实边界样件、跨批次和现场验收另外进行。
