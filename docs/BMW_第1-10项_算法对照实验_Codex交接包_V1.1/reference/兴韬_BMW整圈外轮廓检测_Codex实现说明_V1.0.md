# BMW 整圈外轮廓提取与缺陷对比：Codex 实现说明

**模块版 V1.0｜2026-09-11｜适用仓库：`wjstx0425/anomaly_xingtao_new`**\
**用户指定分支：`feat/bmw-four-camera-runtime-cleanup`**

> **本轮只做一个模块：单视角整圈可见外轮廓的自动提取、刚性定位、标准对比、异常定位和覆盖检查。**
>
> 用户已完成钢印判断，当前优先级改为轮廓。不要重新开发钢印，不做左右件自动识别，不同时展开冲压方向、孔槽检测或新深度模型训练。
>
> 标准件允许一次人工辅助建模；待测件必须自动处理整圈，不得预先指定缺口位置，不得把“局部缺口演示成功”当成“整圈检测完成”。

## 0. 给 Codex 的任务摘要

**输入：** 一个已确认的参考件模型，以及同一型号、同一视角、同一成像规格的待测图。\
**输出：** 标准轮廓与待测轮廓叠加图、所有超差边段、提取不可靠的边段、逐点偏差、配置与结果记录。\
**主路线：** 整件粗分割 → 沿整圈边界精定位 → 受约束的二维刚性对齐 → 双向点到轮廓线段距离 → 连续超差及完整覆盖判定。

计算依赖以现有 Python、NumPy、OpenCV 为主。先做独立离线入口，验证后再接入 BMW 八视图运行链。不为本模块加载无关的 YOLO、EfficientAD、相机 SDK 或 OCR 模型。

**首轮完成 C0—C3：本地核对、整圈标准建立、整圈待测提取、完整对比闭环。** C0 复现旧缺口结果只是基线检查，不是本轮最终交付。C4 再做真实重复取放与阈值验证，C5 接入现有运行链。

建议交付的最小使用体验：

```text
建立标准：打开参考图 → 辅助分割 → 检查整圈 → 设置基准与参数 → 保存
日常检查：选择该配置 → 输入待测图 → 自动显示整圈差异及无法检查的位置
```

## 4. 输入、坐标和图像通道合同

### 4.1 输入必须显式携带的信息

每次检查至少记录：`capture_id`、`hand`、`view_id`、所选通道、图像实际尺寸、配置版本、参考版本。手别/型号由现有显式配方给出，本模块不自动识别左右件。

第一轮直接使用这两张 `fused` 图。后续比较短/长曝光时，应按视角或边段固定、验证通道策略。禁止为每个待测件挑选“最像标准”的通道，从而消除缺陷。

现有 `fused_only_sources()` 会把融合图放入多个数组位置以兼容接口；这不是真实多曝光。检查 `source_kind`，不能把重复数组当独立证据。[R6]

### 4.2 坐标统一

- 原点在左上，x向右、y向下；所有测量距离以**本次参考输入图像像素**为单位。
- ROI统一为 `[x1,y1,x2,y2]`，右下半开；图像索引为 `[y,x]`，不要混用。
- 所有曲线点在文件中保存为浮点 `[x,y]`。闭合顺序、起点和弧长必须随参考版本固定。
- 允许缩小图片做粗分割或界面显示，但精确提边和距离结果必须回到原输入坐标，记录缩放/裁剪变换。不能直接使用YOLO的640尺寸或Template缩小后的坐标。
- 参考图与待测图的尺寸、裁剪、畸变处理规格必须匹配。不匹配时ERROR，不静默resize对齐。
- `T_test_to_reference`统一为3×3齐次矩阵，仅含旋转和平移；同时保存其逆，用于将异常框画回原待测图。

若使用 `warpAffine` 或 `remap`，明确传入的是前向矩阵还是逆采样映射，编写已知平移/旋转测试。图像可用线性插值，离散mask用最近邻；测量点优先直接变换坐标，避免反复warp造成边界漂移。[O3]

读取RGBA输入时明确转换为BGR/灰度，alpha透明区域应作为无效采样域处理，而不是有效黑色背景。非8位输入暂不隐式转uint8；除非项目已有经过验证的转换规范，否则拒绝并报错。

### 4.3 输入不可被新模块修改

当前模型可能共享同一ROI数组。新增模块必须只读共享图像，画图、阈值化、填充均使用副本。轮廓检查**不继承**Template、YOLO、EfficientAD的忽略mask；内部孔也不能通过修改原图来屏蔽。

## 5. 标准件：一次辅助建立，形成整圈参考模型

### 5.1 建模操作流程

`teach`工具应支持放大、平移、框选整件区域、前景/背景笔刷、叠加预览、撤销和保存。优先复用钢印已有交互工具的显示与坐标转换。

1. 读取参考图并检查图像规格。
2. 框选覆盖完整零件及足够背景的整件ROI，必须包含上下小脚，不得紧贴或裁掉边界。
3. 使用GrabCut辅助分割：矩形初始结果不正确时，用前景/背景标记修正。
4. 提取外轮廓并叠加到参考原图，在100%或更高倍率检查整圈。
5. 设置独立定位基准，指定必要的角点/窄结构段，保存参考模型。

GrabCut的确定前景/背景是硬标签，可能/不确定前景背景可以改变；它是本阶段标准辅助工具，不等于已验证的自动测量算法。[O1]

### 5.2 标准应保留的几何

必须保留上下突出小脚、凹口、阶梯、上部弧边、左右边的真实凹凸结构。不用凸包代替轮廓，不用大尺度闭运算填平缺口，不强烈简化曲线。[O2]

内部孔轮廓另存为可选定位信息，但不计入本轮外周长。外部凹槽是外轮廓的一部分，不能像内孔一样忽略。用于计算内部/外部符号的“外轮廓内部mask”可以单独生成，但不能修改测量原图或抹掉外部凹槽。

允许人工纠正**标准图上可见的真实材料边界**；看不见的部位不能手绘成“已观测标准”。若不能确认整圈，模型保持草稿并记录问题边段，不能宣称完整标准已建立。

### 5.3 参考数据结构

最少保存：

```text
reference_bundle/
    reference.png                  # 参考输入或受控相对路径
    reference_foreground_mask.png  # 经确认的分割；非在线硬约束
    contour.npz                    # 原始密集点、弧长采样点、段ID、法向
    reference_overlay.png          # 人工核对用整圈叠加图
    recipe.json                    # 图像、基准、边段、参数、版本
```

`contour.npz`建议字段：`dense_xy`、`sample_xy`、`s_px`、`cell_length_px`、`inward_normal_xy`、`arc_id`、`required_mask`、`corner_mask`。加载使用 `allow_pickle=False`，校验shape、数值有限性、版本及图像规格。

原始密集轮廓用于保留小结构；均匀弧长采样用于组织检测与覆盖统计。采样间距先以约1个输入像素作为开发起点，并验证最小目标缺陷；不要把固定点数100或200当成任何零件通用配置。

参考曲线存N个不重复终点，周期闭合由索引定义。每个采样点负责一个固定长度弧长单元，长度之和等于参考周长。这样覆盖率不会随待测缺陷或丢点改变分母。

法向方向通过参考mask的内外关系验证，不只凭屏幕坐标中的“顺/逆时针”猜测。局部平滑只用于估计稳定切线/法向，不能替代原始测量轮廓。尖角单独标记，不用跨角点的大窗口平均。

## 6. 定位：只去除放置误差，不能吸收缺陷

### 6.1 默认二维刚性变换

使用独立锚点，求：

```text
最小化 Σ w_i × || R p_test_i + t − p_ref_i ||²
约束：RᵀR=I，det(R)=+1
```

推荐用NumPy实现二维刚性最小二乘，或复用已验证的等价实现。不要直接将允许缩放的相似变换当成刚性变换。禁止仿射拉伸、镜像、自由缩放及非刚性形变。

同一图像的姿态补偿不等于“零件尺寸标准化”。如果真实变化是尺度或透视变化，应保留它或报告姿态不适用，不能为了降低误报就自动归一化。

### 6.2 两个孔的可复用起点

旧局部包中使用的两个候选锚点ROI，坐标仅对2047×1545上传图适用：

```json
[[1510,355,1615,465],[1245,1140,1380,1285]]
```

孔边缘拟合、中心质量、中心间距变化和旋转/位移范围都要校验。拟合不稳定或孔被遮挡时REVIEW。不能把左右孔标签互换后选择“对得最好”的关系。

**两个锚点足以估计二维旋转和平移，但不能独立证明整件没有三维姿态或局部几何变化。** 应加入不参与拟合的第三个检查特征/稳定基准边段，或在真实重复取放试验中验证适用边界；不要把很小的拟合残差当成全局定位质量的唯一证明。

检查目标包含孔所在安装耳的变形时，需重新评估锚点是否会随缺陷移动。定位自由度决定了哪些变化被当作姿态消除，必须在结果说明中保留这一限制。

### 6.3 定位失败的处理

可靠提取的锚点间几何关系异常可以作为单独证据保存；没有足够证据区分几何异常与提取错误时REVIEW。不要继续使用单位矩阵、上一个零件矩阵或全轮廓自由配准后判PASS。

当前Template输出的 `best_shift_x/y` 属于缩小模板的坐标，不能直接用于原图轮廓。轮廓模块应有明确、独立的定位矩阵或经测试的坐标转换适配。[R4]

## 7. 整圈待测轮廓提取：粗分割与局部边缘互相校验

### 7.1 主体粗分割只产生候选，不直接宣布整圈有效

默认实现一个可复现的参考辅助GrabCut粗分割器；光照足够简单的场景可替换为局部阈值/背景差分后端，但不必首轮同时实现全部后端。

在线不得需要人工重新描边。参考mask可用于设置**可改变的概率初值**，不能将完整正常形状直接强制标为待测前景。

具体约束：

- 边界搜索区域内，所有像素必须允许根据待测图像改变类别。不得把“标准件这里有材料”作为确定前景条件。
- 确定前景只允许来自经待测图像验证的稳定主体种子；不能覆盖被检小脚或潜在缺口。种子证据失效则REVIEW，不继续强迫该位置存在材料。
- 确定背景只用于经验证的远端背景/夹具区域，不能紧贴名义轮廓。参考外包络之外也不能全部强制背景，以免删除较大余料。
- 整件ROI保留足够扩展空间；粗分割必须观察ROI内当前图像，而不仅是一个窄参考边界带。
- 不将每次分割都裁切到“允许材料区域”之后再测量，容差只能在最后用于判定。

粗分割保留分支/连通域诊断信息。选择包含稳定主体种子的主要零件区域，不简单取整图最大亮块；亮螺钉不能成为零件。出现多个有意义的主体分量、ROI触边或断裂时记录异常，不因只保留最大分量而无声丢弃其他结构。

使用 `findContours` 的外轮廓与密集点模式作为起步；具体接口行为见[O2]。**分割得到一个闭合多边形，不代表其所有边都被图像支持。**

### 7.2 沿参考整圈布置局部边缘剖面

对每个平滑参考采样点 `r_i`，沿内法向 `n_i` 采样：

```text
p_i(u) = r_i + u n_i
u > 0：向参考零件内部
u < 0：向参考零件外部
```

在待测图原坐标读取剖面时使用 `T_test_to_reference` 的逆映射；或一次性warp到参考坐标，避免反复重采样。用局部剖面的灰度变化、两侧材料/背景证据寻找实际边缘。工业局部测边可以参考HALCON的剖面测边思路，但本项目不要求购买或依赖HALCON。[O4]

建议每个采样位置保留多个候选及其：

```text
candidate_xy, normal_offset_u_px,
edge_amplitude, local_contrast, polarity,
foreground_background_support, clipping/validity,
selected_or_rejected_reason
```

候选选择基于图像证据和有限连续性，不选“最接近标准位置”的候选来降低偏差。不允许缺候选时自动设 `u=0`。

局部明暗极性可按已验证边段设置。不能假定整个金属件都“内亮外暗”；候选多峰、反光反转或背景接近时须保留歧义结果。

### 7.3 搜索范围与验收容差完全分开

`search_inward/outward_px` 用于找真实边缘；`tolerance_inward/outward_px` 用于最后验收。

例如，本轮旧缺口约11.5像素，搜索范围显然不能设为4像素容差。但“±40像素”也只能是新实现的调试起点，不能据此保证大缺陷、全部小脚或全部边段都已覆盖。

搜索半宽应同时考虑最大预期形状变化、定位误差与邻近边距离。若窄小结构的另一条边已经进入剖面，切换局部二维处理；不能把窗口缩得比目标缺陷还窄并继续宣称同样能力。

超出剖面范围时：检查独立粗分割是否显示远处真实边界/结构消失。证据充分则报轮廓异常；证据不足则REVIEW。**不得把搜索不到当作没有偏差。**

### 7.4 候选路径的连续性不能抹平缺口

可以使用相邻剖面候选关联或有限代价的路径优化，但连续性只用于避免跳到纹理边，不能将真实尖锐变化平滑回正常形状。

首轮优先实现透明、可输出中间结果的候选关联。代价中不使用强“靠近零位移”项；边缘偏差较大本身不是剔除该候选的理由。保留突变/角点分支，无法区分时标为UNKNOWN。

用合成窄缺口和真实缺口检查：无论是否启用候选关联，目标异常不能被自动补平。缺口最深处和异常两端都要保留。

### 7.5 尖角、小钩、窄槽和轮廓拓扑变化

这些位置的实际边界可能不是参考法向的一条单值函数，因此**法向剖面不能作为唯一通路**。

在参考角点/窄结构区域以及待测中出现突变的区域，使用局部二维图像重新提取密集边缘/分割轮廓。匹配对应边段时同时检查空间位置、相邻拓扑与边方向。一个小脚两侧不能因距离接近而彼此替代。

局部二维提取区域是标准建立时的结构区域或运行时自动触发区域，不是事先框出已知缺陷位置。其边缘必须来自当前图像，不得沿标准曲线插值造边。

### 7.6 整件粗分割是“越界检查”，避免只在标准附近搜索

在粗分割的完整外轮廓上，再检查所有实际分量/边段是否能够对应到参考及有效检测域。检查新增突出、完全消失的小脚、离参考很远的边界，以及ROI边缘截断。

这一步防止仅沿参考窄带搜索时遗漏大余料或大变形。粗分割不可靠的远端边界不能直接作为确定缺陷，但也不能被丢弃后PASS，应报告无法确认或大形状变化候选。

### 7.7 最终提取结果可以包含开放边段

在证据充分的样本上，应得到完整闭合外轮廓。暗边/遮挡无法处理的样本允许输出多段实际观测曲线，但必须同时输出缺失弧段。

允许为显示画虚线连接缺失位置，但这些线属于 `display_only`，不能参与距离、覆盖或面积计算。严禁将未知待测边缘用标准轮廓补齐。

## 8. 整圈比较：双向距离、方向和异常弧段

### 8.1 双向点到线段距离

标准轮廓为 `C_ref`，刚性对齐后的待测轮廓为 `C_test`。同时计算：

```text
d_test_to_ref(q) = min distance(q, each valid segment of C_ref)
d_ref_to_test(p) = min distance(p, each valid segment of C_test)
```

使用点到**线段**距离，不只是点到稀疏顶点距离。对于线段端点a、b及点p：

```text
t = clip(dot(p-a, b-a) / dot(b-a, b-a), 0, 1)
closest = a + t * (b-a)
d = norm(p - closest)
```

零长度线段单独处理。不能对未知间隙建立虚假连接线段。点到轮廓线段的测量含义可参考[O5]。

距离变换可用于加速候选搜索，但精确比较应保留矢量线段；OpenCV距离变换求的是到最近零像素的距离，二值编码不能反。[O6]

相邻但不同的结构边可能错误成为最近邻。对窄结构优先限制在对应结构弧段及其邻域内匹配，同时保留全局异常检查。搜索域不足或对应关系不明时记录歧义，不退化成错误的小距离。

### 8.2 偏差符号统一：向内为正，向外为负

对当前轮廓点q，若它位于参考轮廓内部，`signed_test_to_ref=+d`；在参考外部则为`-d`。

对参考轮廓点p，若它位于可靠待测轮廓外部，`signed_ref_to_test=+d`；位于待测内部则为`-d`。这样两条序列在简单缺口处都表示向内/缺失趋势。

待测轮廓不完整、内部关系无法定义时，不填充闭合后强算符号；可保留局部法向偏移和无符号距离，符号为null/unknown。尖角、对应歧义处也不强行推断。

**`normal_offset_u_px`、同一行横向距离、最短欧氏距离是不同量。** 结果分别命名，不把它们都叫“缺口深度”。

### 8.3 容差与连续超差

每个参考弧段可配置不同向内/向外容差及最短连续异常长度。第一轮先支持全局默认和少量结构段覆盖，不为每个像素手调一套阈值。

对有效采样点，超过相应方向容差形成超差单元。按参考弧长连续性聚合，不按原图y行聚合。首尾是相邻单元，跨起点的一个缺陷应合并成一个事件。

默认不跨未观测单元合并。需要跨少量有效非超差点合并时，记录合并间隙，区分“实际超差长度”和“事件跨度”。不能把忽略区/未知区长度加入真实超差长度。

旧包的4像素、15像素仅保留为开发回归起点。**尖锐但较短的大偏差不应因为没达到15像素就直接PASS**：应配置独立尖峰证据规则，或至少输出REVIEW候选；具体边界由甲方目标缺陷和实测决定。

### 8.4 不以整体相似度代替局部判定

全局IoU、面积差、平均距离或Hu矩相似度可作诊断指标，但不是唯一判据。面积几乎不变的小脚弯折，以及占整件比例很小的缺口，都应由局部证据发现。

可选的材料区域差分，只有在当前mask可靠且闭合时才计算：

```text
E = 必须存在材料的参考内包络
A = 允许存在材料的参考外包络
B = 当前观测材料区域
少料候选 = E \ B
多料候选 = B \ A
```

该结果用于辅助定位/解释，不用于修补B，也不替代双向距离。区域不可靠时面积结果为null。

### 8.5 事件输出

每处事件包含：事件ID、结构/弧段ID、向内/向外/混合、两方向最大距离、连续超差参考弧长、峰值点、原图与参考坐标的范围、图像证据质量、可能的原因说明。

原图事件框由实际异常点通过逆变换计算，不把参考框直接画到待测图。两方向事件在同一参考弧段可合并，避免一个缺口重复计数；不要求真实整圈输出只能有旧包那1处异常，新增候选需逐一回看。

## 9. 覆盖检查与状态：完整闭合图形不等于完整检测

### 9.1 覆盖分母固定在参考模型上

定义：

```text
L_all = 参考整圈周长
L_required = 配置中所有必检参考弧长单元的总长度
L_observed = 必检单元中，有有效当前边缘观测与比较结果的长度
```

至少记录：

```text
required_fraction_of_perimeter = L_required / L_all
observed_required_fraction = L_observed / L_required
unobserved_required_length_px
longest_unobserved_required_run_px
full_perimeter_configured
required_coverage_complete
```

本轮默认整圈必检：`required_fraction_of_perimeter=1`、没有排除段。任一必检单元未完成可靠比较，不得凭全局99%之类阈值签发整圈PASS。默认未知长度上限为0；不要通过调小分母、删掉暗边或增加ignore区来让结果通过。

将来确有夹具遮挡需显式排除时，需列出原因与配置变更。即使其余必检段均通过，也只能显示“已配置边段通过”；`full_perimeter_pass`必须为false。不得把“整圈目标”悄悄改成“容易的边段目标”。

### 9.2 局部无边缘不必一律当成相机错误

如果当前图像清楚、独立粗分割表明某个小脚确实消失，可输出确定轮廓异常，即使那段名义轮廓没有对应边。此时提取覆盖仍如实记录不足，事件说明“结构缺失/超搜索范围的形状变化”。

如果只是暗边、强反光、多候选、遮挡或提取不稳定，没有充分证据，则REVIEW。两者都不放行，但不能把它们混在同一“缺陷召回”统计里。

### 9.3 模块状态规则

优先复用本地钢印模块的等价状态；下面给出需要保留的语义：

| 条件 | 状态 | 必须保留的信息 |
|---|---|---|
| 图像/配置/参考缺失、规格不符、程序错误 | ERROR | 错误码、输入与版本；已有异常证据不丢弃 |
| 存在充分证据的超差/明确结构变化 | NG | 全部已确认事件；同时保留未观察边段 |
| 无确定NG，但定位、提边、覆盖或判定存在未解决疑问 | REVIEW | 原因、未知弧段、候选事件 |
| 输入有效、全部必检段完成且没有超差及未解决候选 | PASS | 本视角规定外轮廓通过；不是整件放行 |

ERROR优先于NG，NG优先于REVIEW，再到PASS。某处已确定NG而另一处看不清时，模块可为NG，同时`required_coverage_complete=false`；不能丢掉未完成信息。

未标定阈值的开发结果记录 `validation_level=development`。独立CLI永远不直接发整件放行指令，`whole_part_release=null`。集成后由既有总判定结合钢印、原模型和必检项完整性决定。

## 11. 接口、离线命令和证据

### 11.1 纯算法接口建议

名称可与已有代码调整，但职责保持分离：

```python
# 以下是目标接口示意，不是已有可直接调用的API。
teach_reference(image, draft_config, annotations) -> ReferenceModel
estimate_rigid_pose(image, reference, config) -> RegistrationResult
extract_full_outline(image, reference, registration, config) -> OutlineObservation
compare_outline(reference, observation, config) -> ContourCheckResult
write_evidence(image, reference, observation, result, output_dir) -> None
```

`OutlineObservation`应同时含实际曲线、有效性、候选、未知参考弧段、粗分割诊断。`ContourCheckResult`不持有可被其他模块修改的共享图像；大数组保存在证据文件，结果对象保存结构化数值与相对路径。

错误作为可检索的状态/异常传播，不能 `except: return PASS`。提取失败的位置在输出中保留，不过滤后重新计算较高覆盖率。

### 11.2 目标CLI

**以下 `bmw-contour` 是待新增入口，当前远端未注册。** 实现后在现有环境中运行；不要为了本模块自动升级CUDA、PyTorch、Ultralytics或OCR依赖。


参考工具还应支持非交互加载已画好的mask/标记，便于无GUI电脑及自动化测试。必须区分“人工确认标准”与“自动检查待测”，不能在批量检测中停下来要求每张图重新标注。

建议单张`inspect`退出码：0=本模块PASS，10=NG，20=REVIEW，2=ERROR；明确0不等于整件放行。`evaluate`退出码只表示批量执行是否完成，判定统计在报告中，不能因数据里含NG就被当成程序崩溃。

### 11.3 必需证据文件

```text
results/.../<capture_id>/
    result.json                 # 状态、版本、范围、覆盖、定位与事件
    reference_overlay.png       # 标准原图及整圈参考
    test_outline_overlay.png    # 待测原图及实际提取轮廓、未知段
    comparison_overlay.png      # 参考坐标下两条轮廓、异常、未检段
    displacement_profile.png    # 横轴为参考弧长，不再固定为图像y
    contour_samples.csv         # 参考采样点、对应点、偏差、有效性
    test_segments.npz           # 实际曲线；未知间隙不造连接边
    events.json                 # 每个候选/确定事件
```

根据需要追加局部灰度剖面和粗mask。证据保存失败应显式报错；采用临时目录/文件写完再发布，避免半写结果被当成完整成功。默认不覆盖已有运行目录。

`contour_samples.csv`最少字段：`arc_id, sample_id, s_px, cell_length_px, ref_x, ref_y, test_x_ref, test_y_ref, valid, invalid_reason, normal_offset_u_px, signed_test_to_ref_px, signed_ref_to_test_px`。双向采样不一一对应时分别输出两个表，不伪造对应值。

### 11.4 结果结构的最少字段

| 分组 | 字段 |
|---|---|
| 身份 | `schema_version, check_id, capture_id, hand, view_id, reference_version, config_version` |
| 范围 | `scope=single_view_outer_contour, related_requirements=[5,10], covered_subscope, full_perimeter_configured` |
| 判定 | `status, reason_codes, validation_level, whole_part_release=null` |
| 覆盖 | 第9节全部覆盖量；未知弧段列表；`full_perimeter_pass` |
| 定位 | 两方向矩阵、角度、平移、锚点、质量检查及失败原因 |
| 几何 | 双向最大/分位距离、全部事件、可选区域差；明确pixel单位 |
| 审计 | 图像来源、实际尺寸、参数快照、运行耗时、证据相对路径 |

`full_perimeter_pass`只有整圈被要求、整圈可靠完成且模块PASS时为true。没有实测依据的置信度只能叫“算法质量分数”，不能声称统计概率或现场检出保证。

## 12. 与已完成钢印及八视图的集成

### 12.1 先独立，后复用现有规则入口

C0—C3期间只新增离线功能，不修改现有主程序的显示与放行。C5再读取本地钢印代码，按其已经建立的检查项机制接入轮廓。

远端快照的 `EightViewInspection.__post_init__` 要求最终状态与原结果融合一致；直接替换其 `final_status` 或只在UI上改文字会破坏一致性。因此应复用本地已扩展的总判定，或者有测试地扩展结果合同；不能在显示、保存、CLI摘要三处分别算不同结果。[R5]

原25条模型结果保留，新增轮廓是独立检查项。若本地钢印已引入 `requirement_results`，优先沿用；未引入时可以增加独立规则结果集合及统一总汇总，但不重构所有模型。

### 12.2 运行时连接

复用当次采集的只读图片及源通道，绑定 `capture_id/generation/view_id`。不要从相机全局`last_sources`中延迟读取已经更新为下一件的图片；在提交任务时固化本件快照。

重置或新工件开始后，旧轮廓任务不得覆盖当前界面。工作线程只运行算法，UI线程显示；保存时同时保存对应版本与图像身份。没有启用本模块的旧配方维持原行为，启用的新配方按完整性检查，不允许缺结果默认PASS。

### 12.3 多视角扩展

先完成本视角。之后每个视角独立建立参考轮廓、定位基准和容差，不直接叠加不同相机的二维轮廓。

只在配置要求的视图运行该模块，不能强迫每个视图都看见整圈。某视角未配置，不宣称该视角轮廓通过；不同视角合起来覆盖的物理部位需要显式清单，不能把8张投影称为完整三维量测。

### 12.4 数据与性能

热路径预加载参考、弧长采样和局部搜索数据。计算大图剖面时矢量化或分块，不构造无上限的N×M距离矩阵。可用距离图/空间索引缩小线段候选，但不得因此跳过大异常。

分别记录定位、提取、比较、证据保存耗时，统计本机单视角与完整流水线的p50/p95。不在未测试时承诺每帧毫秒数或整线节拍；不要为满足速度而偷偷缩小检测范围或图像分辨率。

## 13. 必须实现的测试与验收区别

### 13.1 软件测试清单

| 编号 | 测试 | 必需结果 |
|---|---|---|
| T01 | 参考图对自身 | 距离接近数值精度；不能仅因文件路径相同直接PASS |
| T02 | 已知二维平移/旋转 | 刚性定位方向正确、异常点原图映射正确 |
| T03 | 缩放/局部弯曲 | 不被允许的定位自由度吸收，不因resize回正常而PASS |
| T04 | 上、下、左、右多个位置分别合成缺口 | 全周自动发现，不依赖已知左侧ROI或缺陷文件名 |
| T05 | 合成向外突出 | 双向比较和整件粗检查能发现；不被参考概率mask强制裁掉 |
| T06 | 上/下小脚变形、消失 | 保留结构证据；窗口外找不到不能返回零偏差 |
| T07 | 缺陷跨参考起点 | 合并为一个连续事件，长度不重复计数 |
| T08 | 尖角、近邻双边、窄槽 | 不匹配到错误邻边，不用凸包填平凹口 |
| T09 | 同面积的局部形变 | 不因面积/IoU正常而放过 |
| T10 | 反光、暗边、低对比、遮挡 | 质量/未知状态正确；闭合候选不等于有效观测 |
| T11 | 人工补线或算法插值 | `display_only`不参加距离和覆盖 |
| T12 | 参考先验陷阱 | 较深缺口/大余料不会被硬前景/硬背景种子填平或剪掉 |
| T13 | 比法向搜索带更大的异常 | 粗分割发现或明确REVIEW，不能因窄带失配直接PASS |
| T14 | 内孔灰度变化与表面纹理变化 | 不应被错误计为外轮廓缺陷；但定位孔受影响时必须报告 |
| T15 | 缺输入、错尺寸、ROI越界、透明无效区 | ERROR/REVIEW，不自动缩放或填零通过 |
| T16 | 将关键段删掉/只剩99%覆盖 | 不能显示整圈通过；分母固定，未知段保留 |
| T17 | 一个确定缺陷＋另一个未知段 | 缺陷证据和覆盖不足均保存，不互相覆盖 |
| T18 | 图像文件名交换normal/defect | 判定不变，证明预测不依赖标签 |
| T19 | 参考/待测数组只读性 | 检查前后原数组不变；其他模型结果不被污染 |
| T20 | 证据写盘失败、重跑同capture_id | 不发布伪完整结果，不覆盖既有证据 |
| T21 | `fused_only` | 重复数组只算同一来源，不伪造多次一致验证 |
| T22 | 钢印及旧模型回归、异步重置 | 已有功能不退化；旧任务不覆盖新件结果 |

合成试验标为synthetic，只验证软件逻辑，不等于实际金属成像下的检出率。

### 13.2 对现有两张实图的检查

应输出完整参考轮廓和完整待测候选，并展示每段有效性。左侧缺口应被自动报出；上弧暗边、底部暗边、小脚附近要逐段回看。

**不能以“又找到了左侧同一缺口”作为全模块完成标准。** 也不能强行要求这对图整圈只有1处NG，从而把其他真实差异或提取不确定性压掉。新增候选需要证据和解释，未可靠处理的区域必须明确列出。

### 13.3 真实数据验证

先同一合格件做10—20次真实取出、放回、拍摄，作为开发级重复性试验；再采集多件质量确认合格件和真实缺口/余料/变形样件。分别估计装夹/成像波动和正常制造波动。

按物理零件和取放组拆分调参与验证，不能将同一次取放的多曝光/重复帧分入两侧。两张现有图片只能作开发样例，不能代表独立工业验证。

`validation.csv`建议字段：

```text
sample_id,physical_part_id,placement_group,split,hand,view_id,
image_path,channel,ground_truth,annotation_path
```

路径相对manifest。标签只供`evaluate`统计，不能进入`inspect`的候选选择。未知物理ID明确缺失，不能假造多件独立样本数量。

报告至少分开列出：

- 正常件NG比例、REVIEW比例、ERROR比例，以及所有非PASS比例。
- 缺陷件确定NG检出比例，与“NG/REVIEW/ERROR阻止放行比例”；后者不能冒充缺陷识别召回率。
- 整圈覆盖完成率、各结构段未知率、每次运行及每件样本的耗时。
- 按缺陷类别、位置和尺寸的结果；没有边界样件或最小缺陷标准时标为待验证。

容差依据图纸/边界样件和重复性试验确定。正常波动接近或超过要检出的变化时，应改进成像/夹具或方法，不通过无限放宽容差解决。

## 14. 分批实施与每批交付

| 批次 | 任务 | 完成证据 |
|---|---|---|
| C0 | 核对本地分支、钢印代码、环境；找到两张图；可选复现旧包 | 真实代码地图、图片规格、已有测试基线；不改旧业务逻辑 |
| C1 | 完成整圈标准辅助建立与保存 | 含弧边、上下小脚和凹形结构的参考叠加图；可加载的模型；未知处明确标注 |
| C2 | 完成整圈待测自动提取与有效性 | 待测实际边缘、剖面/二维角点结果、覆盖图；不是只扩一个左侧窗口 |
| C3 | 完成双向比较、事件、覆盖状态及单图CLI | 真实缺口自动定位；整圈偏差与未知段；T01—T18主要逻辑测试 |
| C4 | 真实重复取放、多合格件和边界异常验证 | 独立报告、可解释的阈值与适用范围；不把合成结果当现场验收 |
| C5 | 接入本地钢印规则层及八视图结果/保存/UI | 旧功能回归、完整性与异步测试；逐视角扩展计划 |

每批都报告“已实现、已运行测试、仍未验证”三个状态。说明实际执行命令、修改文件和输出路径，不以“已写代码”替代“已运行”。

C1/C2存在不可见暗边时，应具体输出该段及失败证据，并继续完成可复用的全周框架；**不能把它标PASS，也不能以人工删除该段来宣布C3整圈验收成功。**

### 最小功能交付与量产验收的区别

功能交付：能够一次建立标准，对未知待测图自动搜索整圈，计算局部差异并诚实报告未知区域。\
实图整圈验证：整圈可见边缘均有真实图像支持，正常/异常样例可解释。\
量产验收：在明确最小缺陷、公差、节拍和现场样本统计条件下通过验证；本文未提供这些条件，不做检出率承诺。
