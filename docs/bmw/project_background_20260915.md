## 2. 项目整体目标

产品大类为**发生器支架**。当前仓库和开发图以BMW左右件为主要落地对象，但目标是可配置的零件检测能力，不能将一个front样本的固定位置写成所有零件的通用规则。

甲方要求同时包含检测算法、尺寸几何、生产防错和系统集成：

1. 匹配自动化产线节拍；支持在线/离线集成；NG后能自动剔废或报警暂停。
2. 检测精度需讨论，可在图纸公差基础上协商适当放宽。原文没有给出统一数值；这不授权算法自行提高公差、降低覆盖要求或将像素阈值当毫米公差。
3. 具有SPC统计过程控制、缺陷图像存储和数据追溯。

目前没有从这份需求中得到明确的节拍数值、最小缺陷尺寸、误判/漏判上限或全部图纸公差。玻璃/传送带来自用户本次会话中的未来成像设想，并非该需求文件已经确定的机械方案。

## 3. 完整22项需求地图

| 原编号 | 项目 | 本项目理解及边界 |
| --- | --- | --- |
| 1 | 开裂 | 已张开可见裂口；需与油污边、模具纹区分 |
| 2 | 隐裂（微裂） | 闭合/内部裂纹可能无稳定表面信号，2D图像只覆盖经确认的可见子集 |
| 3 | 划痕 | 原要求为影响结构强度的深度划痕；可见定位不等于深度/强度测量 |
| 4 | 毛刺 | 指定局部可能划伤气袋的毛刺，位置及尺寸需结合功能定义 |
| 5 | 变形 | 磕碰、扭曲、下塌等；单视角轮廓仅覆盖可见投影变化 |
| 6 | 压伤 | 明显凹陷；明暗异常不能直接换算深度 |
| 7 | 油污 | 大面积或关键区域油污，可能影响贴码/污染气袋；需区分允许油膜 |
| 8 | 表面氧化 | 发白、发黑、发黄等明显变色；需核实真实色彩来源 |
| 9 | 成型挤料 | 堆叠、起皱、拱起、鼓包等，外观证据与高度/厚度量测分开 |
| 10 | 多料/少料 | 相对理论需要的材料富余/不足，外轮廓是其中可观察子范围 |
| 11 | 冲压堵孔 | 冲孔废料片卡在孔内 |
| 12 | 基准尺寸 | 主副定位孔大小/位置/孔边距，基准面平整及相互关系 |
| 13 | 检测点尺寸 | 检测孔尺寸/位置；小脚宽、高、角度、位置度、面轮廓度 |
| 14 | 型面 | 线轮廓度、面轮廓度 |
| 15 | 冲压漏序 | 少一道加工工序、漏孔、混入半成品等 |
| 16 | 冲压方向错误 | 正反、旋转、镜像或成型方向错误 |
| 17 | 左右件混料 | 左右实物混入或标识与实物不符 |
| 18 | 相似件混料 | 不同零件号但外形高度相似的产品混入 |
| 19 | 钢印不完整 | 要素缺失或不清晰 |
| 20 | 钢印错误 | 字符/版本/零件号错误或与零件身份不对应 |
| 21 | 钢印批次倒退 | 回退、重复旧批次等时序错误 |
| 22 | 钢印批次超前 | 钢印日期晚于实际包装检查日期 |

原文“实现”列中的素材学习/规则比对是需求建议，不是已经完成的功能标记。油污既可能是裂纹检测的干扰，也可能本身属于需检缺陷，不能把所有油污统一忽略。

## 4. 本轮两人分工只覆盖什么

分工包当前范围是**第1—10项的算法试验与验证**，不意味着完整22项都在本轮交付。整圈轮廓是最高技术优先级。

| 工作包 | 主负责方 | 当前顺序与交付 |
| --- | --- | --- |
| WP01 数据、接口与基线 | 负责人；协作者协助核对 | 首先提供共同数据清单、实体划分、冻结基线和统一输出 |
| WP02 整圈轮廓 | 负责人 | 与WP03并行；单视角完整提取、偏差证据、未知边段 |
| WP03 表面规则 | 协作者 | 第一份独立任务为R02a细线规则，交真实补检和误报 |
| WP04 检测与分割 | 协作者；负责人管理数据/预算 | 先D01旧YOLO权重输入对照，后续有合格标注再训练 |
| WP05 复核与集成 | 负责人；协作者修复自身模块 | 同一口径比较增益与代价、复跑、选择候选和回归 |

负责人保留需求解释、标准件/质量确认、相机光源夹具决策、共享接口/评估器、数据划分和最终集成。协作者只维护自己的规则/监督适配，不修改现场profile、原权重、公共runner或EfficientAD参数。共享数据只读，源图与真值不原地改写。双方使用独立工作树/分支；文档中的分支名是建议，不要求回退旧SHA。

首轮顺序：G0数据/基线交接 → G1轮廓与细线并行 → G2旧YOLO输入诊断 → G3按共同漏检与标注条件逐个扩展 → G4冻结评估与选型。进度按交付节点，不按未经确认的固定天数承诺。

## 5. 已确定的算法与训练边界

- 无监督深度分支只保留EfficientAD，并冻结权重、输入、ignore mask、后处理和阈值；不重新扩展PatchCore、AnomalyDINO等，历史资产也不删除。
- 当前Template、光痕、YOLO与钢印相关成果保留；轮廓/规则不以EfficientAD是否报NG作为唯一运行条件，否则无法补检。
- 第一轮R01/R02a/D01为离线回放/规则/旧YOLO输入诊断。更高分辨率或固定分块标记 `inference_only`，不能称为重训后的模型效果。
- 后续监督训练需有明确比较问题和真实标注。WP04的S01默认是一至两类**缺陷mask**，例如开裂/划痕；我们为轮廓需要的**主体材料mask**是另一任务，须单独登记，检验不会把真实缺口补回正常形状。
- 上一轮答复的“100训练＋30验证＋50测试”只是受控场景下主体分割试点的数据预算建议，不是甲方要求、WP04缺陷分割统一门槛或已批准训练任务。不能混用两类样本数量。
- 孔槽/堵孔、冲压方向、左右件自动识别暂非本轮主任务；12—14项完整几何公差、PLC/MES、自动上下料及机械改造不在这次软件分工范围。产品总需求仍保留，不能因阶段排除就从总覆盖表删除。

## 6. 与当前BMW实现的衔接

当前本地运行说明为 `bmw_runtime/README.md`：四相机、两轮、八语义视图，左右配方显式选择。现有左右配方选择不等同于已完成第17项自动混料识别。

本次会话已形成独立front自动定位、几何测量和轮廓采集；8张真实图定位成功，轮廓下部暗面仍有错误分割，不能标为整圈可靠完成。详见 [front自动匹配记录](front_automatic_geometry_20260915.md) 与 [暗面说明](../../artifacts/bmw_dark_segmentation_explained_20260915/README.md)。

当前两孔用于姿态匹配；如果后续检测第12/13项孔位置度，必须另按图纸定义独立基准，不能先用待检孔把图对齐，再据此宣布孔位置正确。小脚到孔的投影垂距可作为开发观测，不等于三维面轮廓度或正式毫米尺寸。

分工包“钢印已完成”应理解为保留已有成果、不重做；当前运行说明明确独立OCR尚未连接主判定和工单规则，所以本次不能将第19—22项业务正确性、日期/批次联动写成已全部验收。

SPC、自动剔废、报警暂停和完整在线集成属于总需求；本次只读需求与背景梳理，未核验这些系统能力已完成。

## 7. 交接与评价口径

每次交付至少包括：变更清单、参数快照、精确命令、环境/资产版本、真实逐图结果、成功与失败图、覆盖缺口、耗时及一页结论。数据记录实体ID/谱系/采集session/左右/视角/原图SHA；同件的重拍、短长曝光、融合、裁剪和增强不得跨训练/验证/测试集合。

评价同时报告补检、新增误报、REVIEW/ERROR、未检覆盖和全视图/全分块总成本。有框/mask才报告相应定位成绩；仅有图像NG不能当成某类缺陷准确定位。缺样本、缺标注、不可观察或缺模态分别登记；空类别不写100%通过。

完整表面、全部闭合隐裂、三维下塌、深度划痕、面轮廓度和生产节拍均需相应成像/量测/现场证据。软件测试、单图演示、像素投影与生产验收保持区分。

## 8. 仍待明确的项目输入

1. 已确认黑色传送带与正上方光源；仍需确认光源类型/尺寸、是否可调或分区补光、相机视角、遮挡及实际运动速度。
2. 图纸/CAD及可用定位基准、各关键位置判废公差、最小目标缺陷。
3. 各类确认样件和允许干扰：正常油膜/油污界限、隐裂外部质量确认、实体ID与像素标注。
4. 产线节拍数值、接口边界、SPC指标、存储追溯周期及第19—22项业务规则。

这些是后续实施和验收的输入缺口，不妨碍继续当前离线轮廓研究。本轮仅补充背景和记忆，没有启动训练、修改检测阈值、现场集成、提交或推送。
