# 实测纯反光模板扣除（2026-09-12）

用户提供两张实际图片。经视觉确认，`dataset/Image_20260912201543028.bmp`为有件图，`dataset/Image_20260912201549452.bmp`为无件反光模板（不要按文件列举顺序反过来）。均4024×3036、uint8 BGR。

## 结果

`results/bmw_reflection_template/20260912_2015_measured/index.html` 包含原图、模板、1:1扣除、80%扣除和饱和区域覆盖图。完整结果为`corrected.png`，左右对比`before_after.jpg`，刻字局部`stamp_comparison.png`。

直接计算 `round(clip(I-R,0,255))`，不配准、不增强、不修补。保留float32有符号差值` signed_residual.npz`，避免8bit减法下溢和掩盖负残差。参考与有件图均无曝光/Gamma元数据，按已保存像素值扣除是近似模型。

公共左背景ROI[300,500,520,2500]原图/模板灰度均值42.95/43.37，平均绝对差1.59，扣除结果均值0.63、中值0。说明相同坐标模板能很好地压低白框背景；不是完整反射层恢复准确率。

独立背景条带配准探索提示向右约1–2px、向下约13–18px可能小幅减少残差，但竖纹使位移不唯一，且改善仅约0.4/255；此次保留不重采样基线，没有据此修改相机或认定真实平移。

## 仍有亮环的原因

有件图19.0798%像素已三通道全255，任一通道>=250占20.3313%；模板没有>=250像素。若输入已剪切为255，扣除不同亮度的模板会变成`255-R`，产生反向模板形状，不能代表原来金属表面。

中央亮残差中约77.7%来自原始三通道全255像素（诊断ROI为中心[2020,1570]、尺度690的椭圆半径平方<=1.3，残差灰度均值>=175）。亮环并非全部已证明由饱和造成；剩余还可能有纹理/局部反光差异。不能以补画方式抹掉后声称恢复。

`source_all255_mask.png`保留原始全白区；`saturation_uncertainty_mask.png`标记任一输入任一通道>=250，红色覆盖图对应这些区域。`negative_residual_mask.png`标记有任一通道差值<0，约16.66%，其中包含背景噪声差，不等同于损伤比例。未过曝也不自动等于真实反射完全去除。

下一次需要把**模板和有件图一起**用相同、更低曝光或增益重拍，使有件图关键表面也未过曝；保持光源、相机姿态、焦距/光圈、Gamma与白平衡一致，并关闭可能改变两次成像参数的自动功能。不能给新的低曝光有件图直接套用当前高曝光模板。此前固定框是否随零件移动的问题已有这组参考提供支持，但跨姿态/工件泛化尚未验证。
