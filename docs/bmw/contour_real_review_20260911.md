# BMW 整圈轮廓：用户指定六张实图诊断（2026-09-11）

本次实际运行了用户指定的 1 张正常图及 5 张轮廓变形图。**五张缺陷图的主要异常位置均有自动候选，但当前实现尚不能可靠判定：同一正常图自检也出现6个NG候选和58个REVIEW候选。** 不能用这组结果宣称5/5准确率或生产可用。

这是现有 C0—C3 算法的实图诊断，不是新的已验收检测器。主算法、钢印、八视图和相机流程没有修改；没有进行训练、提交或推送。

## 定位

从本轮正常图独立选择双暗孔ROI：`[[2940,650,3210,920],[2430,2200,2720,2570]]`。未套用旧2047图窗口。

六图定位均成功。五缺陷图的刚性拟合RMS为0.169—0.818px，孔距变化0.338—1.636px，孔运动1.895—4.546px，绝对旋转角不超过0.1312°。使用开发限值角度2°、运动25px、间距3px、RMS1.5px；没有放宽到探索脚本的更大限值。额外24次ROI扩缩检查全部定位成功。

双孔只能验证本组二维锚点提取和刚性拟合，不能独立确认三维姿态、锚点承载耳无变形或量产重复性。

## 暴露的问题和后续优先级

1. **前景归属不可靠。** 当前在线GrabCut会纳入背景螺钉和画面边缘碎片。正常自检中，螺钉产生了约221px的NG候选；画面角落还产生超过1000px的REVIEW候选。需要用当前图像验证的主体归属约束识别零件，同时保留真实脱离小结构的诊断，不能把背景组件当余料。
2. **暗边与参考定义不稳定。** 底部暗色材料在待测自动分割中再次被误分为背景，粗边进入内部阴影；部分剖面会选择与标准不同的边缘。需要改进图像支持与材料/背景判别，不能强行套参考补齐。
3. **参考法向与细碎候选。** 像素级锯齿、尖角及窄小结构造成313个参考点未确认，待测又增加未知与大量碎片候选；需改进保留真实几何的法向估计/二维角点对应及事件证据质量。
4. **先通过正常自身与多正常件验证，再讨论检出率。** 当前正常自检失效，因此本轮只证明“能产生一些位置正确的候选”；不能用增大容差、删除暗边、只展示指定缺口或把REVIEW算作识别成功来验收。
