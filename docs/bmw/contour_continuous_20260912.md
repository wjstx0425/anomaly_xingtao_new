## 固定条件与实现变化

对照基线为 `artifacts/bmw_contour_reference_20260912/folds_only_normals/` 与 `folds_only_defects/`。本轮没有重新编辑 mask；此前已确认的小脚折痕修订见[参考复测记录](contour_reference_20260912.md)，工装 B 定位见[B 定位复核](contour_fixture_B_20260912.md)。

`report.py` 已逐项验证以下条件相同：参考密集曲线、采样点、法向、每点弧长、必检标记及参考有效标记；八张待测原图的 SHA256；全部 comparison 参数。必检分母始终为 **9485 个样本、9484.4212 px 周长**，包括 49 个参考法向未知点。未知点没有从分母删除，缺失段没有用名义轮廓插值补齐。

向内/向外开发容差仍为 **4 px**，最小连续超差弧长 **15 px**，短段大峰值门限 **8 px**，合并间隔 **0 px**，无局部公差覆盖。本轮没有采用此前仅用于分析的底脚放宽阈值。

新增 `edge_selection_mode=continuous_v3`，旧配置默认 `independent_v2`。参考校准在有限 ±6 px 内结合图像边缘与材料内外上下文保留候选，再利用相邻采样点的连续性消解部分歧义；待测路径从真实图像候选选择，连续代价设上限以保留真实突变。没有候选或路径仍歧义时保持 UNKNOWN。结构转角使用两侧可靠锚点之间的可观测密集边链，参考与待测采用同一坐标定义，再计算二者位移。没有将自动分割的内部暗边直接改写为标准。

自检已观测位置的最大双向距离约 **5.08e-13 px**，即浮点数值零；仍有 **1038.94 px** 必检周长未知，所以零 NG/零 REVIEW 候选不能变成整圈 PASS。normal001 的 5 个 NG 候选均在底脚，包围框集中于原图 **x2479–2609、y2859–2869**，包含精细双向边与粗轮廓的重复/相邻证据，不能称为五个独立缺陷。用户已确认该件正常，因此这仍是实际误报，不因降低候选数而获得验收。

缺陷图覆盖率提高至 **72.47%–76.83%**，但全部 NG 候选数同时增加。更多边段可测意味着更多超差进入统计，不代表精度改善。005、007、020 的最长未知段还略有增加，不能声称整圈断边问题已解决。

## 仍不可靠的位置与原因

已查看最终八图总览。青色测量线覆盖大部分清晰外弧，橙色未知仍集中于暗侧边、细脚、转角和显著形变附近；020 展开小脚等大变化不能依赖参考附近的精细搜索包办，需要保留独立粗轮廓证据。

自检的 1039 个未知样本构成为：参考转角未确认 708、参考图像边校准未确认 239、参考法向未知 49、没有相邻有效线段支持的孤立观测 43。参考侧的不确定性构成共同覆盖上限。额外正常图及缺陷图还有当前图候选缺失、路径歧义、转角锚点/密集边链不足；这些均保留在各图 `contour_samples.csv`，没有为了增加覆盖率而插值或移出必检范围。

下一步应首先核实正常001底脚的允许投影变化，以及参考转角、暗边的可观测定义，再用更多独立合格件测误报约束。当前八张重复使用的开发图不能承担独立验收集的角色。
