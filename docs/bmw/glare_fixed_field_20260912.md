# 固定白框反光场扣除试验

用户指出白框位置/四周亮度规律，要求针对结构去除。此前仅亮度均衡/CLAHE试验不足以否定这种方法。本次按固定加性反光场重新试验，确认矩形亮雾可以显著削弱；目前不是完整真实反射分离。

## 方法

工作假设为 `I(x,y)≈T(x,y)+R(x,y)`：原图由目标图像与固定反光场叠加。此类加性分层模型用于反射分离，但在未知Gamma的8bit BMP上只是近似，不能视为已经标定的辐射模型。[分层模型参考](https://openaccess.thecvf.com/content/ICCV2021/papers/Dong_Location-Aware_Single_Image_Reflection_Removal_ICCV_2021_paper.pdf)。

从第一张周边推定暗背景的5个矩形区采样，以16×16块中值、步长32拟合。场使用双线性/纵向二次的平滑幅值与倾斜、羽化的左右/底边，顶部在画外。SciPy least_squares soft_l1拟合15参数；扣除场不含背景常量偏置。每4个样本留1个验证。参数、初值/上下界、拟合区覆盖图、float32反光场均保存。[优化器说明](https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html)。

同一模板直接用于第二张，没有重新拟合或调整参数。邻近背景块验证误差中位数2.62/255，第二张背景块误差2.71/255，说明这两图背景亮度规律稳定；不是未知真实反射层的精度或独立泛化验收。

## 实测

| 方法 | 第一张右背景中值 | 第一张新增压黑比例* |
|---|---:|---:|
| 原图 |86|0%|
| 扣除65%估计场 |28|4.22%|
| 全量扣除 |0|26.66%|
| 保暗扣除 |17|0%|

右背景ROI为[3450,1800,3750,2300]；*新增压黑指源灰度>=8而结果<=1，占全图比例，不能解释为缺陷损伤比例。第二张对应背景中值86/29/0/17。全量扣除虽去掉大部分背景白框，也严重压黑圆内区域和真实暗部，不能推荐为检测预处理。

保暗公式 `max(I-R,0.2I)` 逐通道限制扣除，保留至少20%原始值。它降低错误黑剪切风险，代价是残留反射和改变对比度，不能称为恢复真实表面。约80%的背景亮度下降来自该公式与测量，不是反光分离准确率。

圆形区域未擅自填补或手工擦除。简单背景反光场在那里明显高估，可能存在局部遮挡/调制，实际来源未确认。原始饱和区域仍单独保存mask，不能因输出不白了就称细节恢复。

- `artifacts/bmw_glare_fixed_field_20260912/outputs/index.html`：两图原图、65%、全量、保暗4种全分辨率PNG及对比。
- `run_model.py`为规范复现脚本：`UV_CACHE_DIR=/tmp/bmw-exposure-uv-cache uv run --no-sync python artifacts/bmw_glare_fixed_field_20260912/run_model.py`；要求outputs不存在。`fit_exploration.py`仅为早期/tmp探索归档，以run_model.py为准。
- `report.json`包含拟合参数/假设/指标，`estimated_reflection_field_float32.npy`保留准确场。`verification.json`确认原图SHA未变、8个输出公式/形状/hash一致、同一场用于两图、保暗版没有上述新增压黑。
- 独立agent背景可分离场也复现白框变弱和全扣压黑现象；仅/tmp探索，不作为正式结果。

## 更完整校正需要什么

先确认换件/移动零件后白框是否固定在传感器同一位置（已向用户询问，尚未收到答复）。若是光路上固定加性反射，可保持相机、曝光、增益、Gamma、光源及造成反光的部件不变，用吸光黑背景遮住真实场景采集反射参考；必须确认这个动作没有改变反射本身。再用该参考逐像素扣除并验证真实细节。

若白框随金属件姿态变化，则不能直接用单个全局模板；需固定姿态参考或按姿态配准/标定。没有相机反射参考时，边缘稳定不保证内部亮度同样可外推。目前可交付外观抑制候选，不能承诺完整消除或生产检测等价。
