# BMW左手可信OK参考库设计

## 目标

将 `bmw_left_normal_20260814_v2` 中用户确认作为正常件采集的52个完整零件发布为左手专用可信OK参考库，并绑定当前左手Demo，用于NG证据与同视角最相似OK图对比。

## 数据与资产

- 输入为 prepared manifest 的52个 `normal/OK` 完整八视图零件，共416张图。
- prepared manifest 中源SHA为空，发布器必须从当前源文件重新计算SHA并写入冻结清单。
- 参考库使用当前左手ROI生成每视角ROI裁剪，同时保留完整原图供光痕对比。
- 发布目录为 `dataset/bmw_trusted_ok_reference/bmw_left_normal_20260814_approved_v1`，禁止覆盖已有目录。

## 兼容策略

- 旧右手可信库继续使用schema v1及固定50件、固定会话和固定目录校验。
- 新左手参考库使用schema v2；参考数量由索引声明，但必须大于0、每视角数量一致、每个零件恰好八视图。
- 左手Demo通过索引路径和SHA绑定参考库；参考匹配只生成诊断证据，不参与四个检测算法或最终OK/NG融合。

## 验证

- 单元测试先覆盖空SHA manifest发布、动态数量v2匹配器加载和旧v1兼容。
- 发布真实416张参考图后校验索引SHA、每视角52张、ROI SHA和匹配器预加载。
- 通过当前左手Demo配置完成加载测试。
