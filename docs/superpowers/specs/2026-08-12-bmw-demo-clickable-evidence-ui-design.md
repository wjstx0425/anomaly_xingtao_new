# BMW八视图Demo可点击证据UI设计

## 范围

只修改现有OpenCV Demo的UI状态、绘图、鼠标事件和测试，不修改Template、光痕、YOLO、EfficientAD的推理、阈值、配置或融合结果。

## 主页面

- 四个算法卡可点击；优先跳到该算法首个ERROR/NG视角，否则跳到首个PASS视角。
- 八个视角卡可点击；只切视角并联动下方证据。
- 当前算法和视角使用BMW蓝色粗边框。
- 光痕仅有`front_left`结果；选择其他视角时明确显示未执行。
- 保留`T/L/Y/E`、`1-8`、`N/P/O`快捷键。

## 双图详情页

点击任一下方有效证据图，在同一1600×900窗口打开详情页。左侧固定为人工确认的可信OK参考，右侧固定为当前检测证据；两侧同视角、同ROI、同方向、同缩放规则。

- Template：512×512对齐参考与512×512差异证据。
- YOLO/EfficientAD：可信参考ROI与当前ROI覆盖图。
- 光痕：从可信参考完整图裁`roi_xyxy`，与当前ROI证据一起顺时针旋转90度。
- NG/ERROR没有可信参考时明确提示，不回退到未批准图片。
- PASS允许放大当前证据，但左侧提示无需NG参考，不增加参考匹配。
- 显示算法、视角、状态、分数、阈值、原因和参考样本身份。

详情页按Esc返回主页面；主页面Esc无动作；Q始终退出；R重置。详情页不响应拍摄或选择快捷键。

## 实现与验证

逻辑命中区域固定在1600×900画布坐标，鼠标显示坐标按实际视口换算。回调只入队，主循环消费。测试覆盖命中边界、算法选择、视角切换、四算法对比图坐标域、PASS/缺参考提示、Esc/Q/R及缩放坐标映射。UI前后不得改变同一检查结果的25项结果和最终状态。
