# BMW 八视图实验室系统交接设计

## 目标

把 BMW 四相机八视图实验室检测从采集、数据准备、ROI、标注、训练、模型检查到 Demo 部署测试写成一份可逐条执行的中文 README，并将实现代码发布到公开仓库的独立分支。

## 发布边界

- 分支：`agent/bmw-eight-view-handoff`，基于远端最新 `main`。
- 包含：BMW 八视图源码、CLI、配置、聚焦测试和本交接文档。
- 不包含：`dataset/`、`results/`、模型权重、Label Studio 数据库、相机 SDK、账号口令和现有 ZS32 工作区修改。
- 文档必须区分“代码已发布”“本机模型已验证”“实体四相机本轮未重新触发”三种状态。

## README 结构

README 依次说明系统边界、四相机映射、环境安装、HDR 采集、八视图数据准备、ROI、Label Studio 标注与复核、训练目录生成、一键训练、训练效果、模型文件、离线部署验证、实时四相机 Demo、常见故障、已知短板和接班检查表。所有命令均以仓库根目录为工作目录并使用 `uv run --no-sync python`。

## 验收

- 分支只包含约定的 BMW 交接文件，没有数据或模型大文件。
- BMW 聚焦单测和所有交接 CLI 的 `--help` 通过。
- README 中引用的仓库内路径真实存在。
- SSH 推送成功，并创建指向 `main` 的 Draft PR。
