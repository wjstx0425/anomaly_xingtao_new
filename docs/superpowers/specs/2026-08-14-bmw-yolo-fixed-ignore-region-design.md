# BMW YOLO固定忽略区域设计

## 目标

在左手八视图Demo中，仅对 `front_secondary` 的固定底座区域启用YOLO后处理忽略框，避免固定工装被判为缺陷，同时不修改公共ROI、YOLO权重、Template、EfficientAD或光痕检测。

## 已确认现场证据

- 最近6次误检框稳定在约 `[1641, 521, 1756, 724]`。
- 误检置信度为 `0.293` 至 `0.377`，当前最终阈值为 `0.25`。
- 忽略区域固定为 `[1580, 450, 1756, 800]`，坐标属于 `front_secondary` ROI图像。

## 行为

- 配置在 `yolo.ignore_regions` 中按视角声明矩形。
- 当检测框中心位于该视角任一忽略矩形内时，该框不参与YOLO最终NG判定。
- 被忽略框仍保留在诊断详情和证据图中，并明确标记为固定区域忽略框。
- 输出判定分数取未忽略候选框的最高置信度；若只有被忽略框，则YOLO为PASS且判定分数为0。
- 未配置忽略区域的旧配置保持原行为；同坐标框在其他视角不被过滤。

## 验证

- 配置加载测试覆盖合法区域、未知视角和非法坐标。
- 预测器测试覆盖 `front_secondary` 固定框被忽略、其他视角同框仍为NG、区域外框仍为NG。
- 使用已保存的现场 `front_secondary` ROI进行一次离线YOLO回放，确认固定底座不再造成NG。
