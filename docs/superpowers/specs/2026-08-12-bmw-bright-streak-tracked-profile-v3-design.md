# BMW 光痕 tracked-profile v3 设计

## 目标与边界

本次只优化 BMW 八视图 Demo 的 `front_left` 光痕分支。Template、YOLO、EfficientAD、25 项结果结构和整件融合规则均不修改。

当前 `raw_profile_v2` 在固定 `81x613` ROI 中只计算中央 9 像素竖带。现场亮痕实际倾斜，固定竖带只在局部与亮痕相交；轻微灰度变化会把同一条肉眼连续亮痕切成多个短段。`bmw_demo_20260812_211302` 的亮痕覆盖和最长连续段均达标，唯一失败原因是 5 行弱响应被解释成真实断点。

现有标签只有 `OK` 和 `NG_NO_STREAK`，没有真实 `NG_BROKEN`。本阶段的可验证目标是：降低正常倾斜亮痕误拒，同时保持完全无光痕样本被拒绝。断续判定继续保留，但只能称为保守规则和合成回归，不能称为真实断续召回验证。

## 方案选择

不采用简单放宽最大断点或断点数，因为这会无差别放过真实断裂。也不采用固定旋转 ROI，因为零件的小幅位置变化仍会使采样带偏离亮痕。

采用 `tracked_profile_v3`：在原 ROI 内计算二维横向局部对比响应，并以带平滑约束的动态路径追踪斜向亮痕。沿路径再执行强弱双阈值连续性分析。

## 算法结构

### 二维局部对比响应

对 ROI 每一行和每个合法横向中心位置计算：

`中心候选带均值 - 左右背景带均值`

候选带、背景带和隔离间距沿用 v2 的局部对比思想。运行前做小窗口中值平滑，但不改变 HDR 图像或其他分支输入。

### 斜向路径追踪

动态规划在二维响应图中选择得分最高的连续路径。相邻行只允许有限横向位移，并对急剧转向施加惩罚。路径允许在 ROI 内开始和结束，因此不会强迫无光痕区域生成贯穿全高的伪轨迹。

路径输出至少包含逐行横坐标、逐行响应、起止行和累计路径得分。路径搜索只在固定光痕 ROI 内运行。

### 强弱双阈值

- 强阈值用于确认路径中存在可靠亮痕种子。
- 弱阈值用于扩展包含强种子的连续路径段，连接局部灰度凹陷。
- 没有强种子的弱响应不能单独构成亮痕。
- 路径上低于弱阈值的区域仍作为真实断点候选，继续计算覆盖率、最长连续段、最大断点和断点数。

阈值只能从 calibration 数据和明确接受的现场正常样本拟合。现有 final-test 只用于报告，不参与第一次拟合。现场误判 `bmw_demo_20260812_211302` 作为明确接受的新增正常回放样本单独记录其身份，不能静默混入旧 final-test。

## 配置与兼容性

新增独立 `tracked_profile_v3` 报告和 Demo engine。旧 `raw_profile_v2` 报告、SHA 和代码路径保留，可通过配置立即回退。

v3 报告必须记录：源 manifest、ROI、拟合 split、额外现场正常样本身份、算法源 SHA、所有几何参数、强弱阈值、连续性阈值、校准和 final-test 结果。Demo 继续对报告做 SHA 绑定。

若 v3 报告、ROI 或参数无效，Demo 按现有配置加载规则失败关闭；不得静默回退到其他光痕算法。

## 可解释证据

结果继续发布：

- 是否存在光痕；
- 路径覆盖率；
- 最长连续段；
- 最大断点；
- 断点数。

新增：

- 追踪中心线；
- 强响应行和弱响应桥接行；
- 路径起止位置；
- 强/弱阈值和横向最大步长。

证据图用不同颜色区分强响应、弱阈值桥接和判定断点，避免把诊断轨迹表述为缺陷分割真值。

## 验收

1. `bmw_demo_20260812_211302` 光痕分支必须从 NG 改为 PASS。
2. 旧评估集的所有 `NG_NO_STREAK` 必须继续为 NG。
3. 旧 calibration/final-test 正常样本不得比 v2 增加误拒，目标为全部通过。
4. 最近现场保存记录做只读回放并列出 v2/v3 变化；不把未人工确认的记录自动视为正常真值。
5. 合成的路径中段明显置暗必须得到 `NG_BROKEN`，完整删除路径必须得到 `NG_NO_STREAK`。
6. 光痕 v3 开关前后，Template、YOLO、EfficientAD 的全部结果逐字段相等。
7. 单次光痕分支应保持实验室快速迭代量级，并报告 CPU 实测耗时；不设工业节拍承诺。

## 已知边界

没有真实断续样本，因此本阶段不能声称断续缺陷召回率。后续补充真实断续样本后，应冻结新的独立测试集，重新拟合弱阈值与连续性阈值，并报告正常误拒、无光痕召回和断续召回三个指标。
