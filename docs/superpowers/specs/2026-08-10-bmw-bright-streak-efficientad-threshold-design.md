# BMW 亮痕提取与 EfficientAD 整件阈值调整设计

日期：2026-08-10
适用范围：BMW 四相机八视图实验室 Demo

## 目标

1. 修复正常件亮痕肉眼明显、现有连通域算法却判为 `NG_NO_STREAK` 的问题。
2. 保留“亮痕必须存在且连续才 OK”的业务规则。
3. 将 EfficientAD 的判定口径从八个模型各自使用 `0.5`，改为八视图联合标定，使当前数据上的整件正常误判率不超过 5%。
4. 保持实验室快速迭代边界，不重新训练 EfficientAD，不改 Template 和 YOLO。

## 已确认的现状

- 亮痕 final-test 包含 17 个正常件和 3 个 `no_streak` 件。现有规则正确拒绝 3 个 `no_streak`，但误拒绝 4 个正常件。
- `bmw_normal_group027` 和 `bmw_normal_group059` 的 ROI 中央亮痕肉眼清楚。失败来自连通域候选过滤，而不是图像中没有亮痕。
- EfficientAD 当前统一阈值为 `0.5`。八视图按“任一视角 NG 即整件 NG”融合后，20 个正常件误判 6 个，即 30%；6 个已知缺陷件全部被检出。
- 初始稀疏缺陷 CSV 在整件正常误判不超过 `1/20` 时最多检出 `5/6`。将 6 个缺陷物理件全部补齐为八视图后，最终联合阈值在当前调参数据上检出 `6/6`，正常误判 `1/20`；这是 `demo_only` 结果，不是独立验证。

## 亮痕算法

### 提取方法

保留现有固定 ROI 和质量检查，将“筛选完整二维连通域”替换为“逐行中央亮脊跟踪”：

1. 对 ROI 做横向 top-hat 或等价的局部背景抑制，突出细长亮结构。
2. 对每一行只在中央搜索走廊内寻找候选亮点，并用候选点与左右背景带的局部灰度差表示该行证据。
3. 使用相邻行最大横向位移约束连接候选点，允许亮痕缓慢弯曲，不要求整条亮痕属于一个连通域。
4. 对短缺口做有限闭合，随后从行级存在序列计算覆盖率、最长连续段、最大缺口和缺口数。
5. 存在性不足输出 `NG_NO_STREAK`；存在但连续性不足输出 `NG_BROKEN`；两者均满足才输出 OK。

现有 ROI、质量检查、结构化指标和可视化接口保持不变；证据图改为显示实际跟踪到的中央轨迹和行级掩膜。

### 标定原则

- presence 参数使用正常件与 `no_streak` 数据分离。
- continuity 参数优先接受当前正常件；由于没有真实断续亮痕负样本，连续性结论继续标记为待补数据验证。
- 当前数据目标是 17/17 正常通过、3/3 `no_streak` 拒绝；如果两类无法同时满足，报告重叠样本，不用硬编码样本名称绕过。

## EfficientAD 整件联合阈值

### 标定输入和决策

- 输入为八个视角的逐图 `pred_score`，按物理零件 ID 聚合。
- 每个视角保留独立阈值，运行时根据 `score >= threshold` 产生该视角 PASS/NG，不再采用 checkpoint 自带的 `pred_label`。
- 整件 EfficientAD 状态仍为任一视角 NG 则整件 NG。
- 联合搜索满足 `normal_part_false_positive_count <= floor(0.05 * normal_part_count)` 的阈值组合；在约束内依次最大化缺陷物理件召回、缺陷图召回，并选择更稳定的较高阈值。
- 生成独立 JSON 阈值资产，记录八个阈值、样本数量、整件误判率、缺陷召回率、输入 CSV 哈希和标定时间。

当前只有 20 个正常测试件，5% 对应最多误判 1 个整件。当前数据同时用于选择阈值，因此资产必须写明 `demo_only=true` 和 `test_used_for_selection=true`，不能把 5% 描述成独立泛化结果。后续新采正常件作为真正的外部验证集。

### Demo 接入

- Demo 配置新增 EfficientAD 阈值资产路径。
- 启动时严格验证八个视角齐全、阈值有限、资产与分数来源字段完整；无效资产导致 EfficientAD 分支 ERROR，不静默退回 `0.5`。
- 界面继续展示每个视角的实际分数与该视角阈值。

- 亮痕新配置、逐样本指标和误判对比报告。
- EfficientAD 八视图联合阈值标定器、阈值 JSON 和整件级评估报告。
- 更新后的八视图 Demo 配置、运行时加载逻辑和中文交接 README。

## 验证

1. 单元测试先复现弯曲/变宽亮痕被旧连通域规则丢弃的行为，再验证新轨迹提取通过。
2. 合成无亮痕和断续亮痕继续分别输出 `NG_NO_STREAK`、`NG_BROKEN`。
3. 在真实 final-test 上逐图复算 17 个正常件和 3 个 `no_streak` 件，并保存证据图。
4. EfficientAD 标定器测试物理件聚合、5% 取整、八视图完整性、阈值边界和确定性。
5. 在 20 个正常件和 6 个缺陷件上重新报告整件混淆矩阵；目标是正常误判不超过 1 个，并如实报告缺陷漏检。
6. 运行 BMW 聚焦测试、CLI help、compileall 和一次离线 Demo 样本回归。

## 不在本次范围

- 不重新训练 EfficientAD、YOLO 或 Template。
- 不声称当前 5% 是独立测试集或工业现场指标。
- 不新增深度学习亮痕模型。
- 不用样本 ID 特判，也不改变“任一必需分支 NG 则整件 NG”的总 Fusion 规则。
