# BMW 八视图 Demo 字体清晰度设计

## 目标

在不改变现有 1600×900 布局、图像区域、网格结构、配色语义和操作方式的前提下，提高中文文字在显示器和投影环境中的清晰度。

## 设计

- 保持现有 Swiss 白底、蓝色强调和一像素网格。
- 新八视图界面优先使用系统已有的 `NotoSansCJK-Medium.ttc`；主标题、最终结果、分支名称和分支状态使用 `NotoSansCJK-Bold.ttc`。
- 小号文字从 15–16 px 调整到 16–18 px；不移动任何面板边界。
- 辅助文字颜色从当前浅灰加深为高对比中性灰，正文继续使用深色。
- 字体覆盖变量继续兼容 `BMW_DEMO_FONT`，并增加 `BMW_DEMO_FONT_MEDIUM` 和 `BMW_DEMO_FONT_BOLD`。
- 不修改旧六视图界面，也不修改模型、阈值、采集或融合逻辑。

## 验收

- 1600×900 输出尺寸不变。
- Medium 与 Bold 字体资源均能加载，粗体和正文字体路径不同。
- 原有界面测试通过，并用同一真实样本重新生成截图进行目视检查。
